# ADR-0002: PDF出力方式の選定

## Context

テンプレートに配置した画像をPDFにして、家庭用プリンタでカラー印刷できるようにする必要があります。

出力解像度は350dpi以上です。

画面の表示密度は350dpiに全然届かないので、画面と同じ解像度のまま書き出すとざらつきます。

## Decision

- Konva Stageの書き出し機能（`toDataURL`の`pixelRatio`オプション）で、画面より高い解像度の画像を作る
- その画像をjsPDFでPDFに埋め込む
- PDFのページサイズは実寸（mm）で指定する
- pixelRatioは350dpi分のピクセル数から逆算する
    - 必要px = 出力サイズ(mm) ÷ 25.4 × 350
    - pixelRatio = 必要px ÷ Stageの表示サイズ(px)
- 画面プレビューは普通の解像度のままにして、書き出す時だけ高解像度にする

## Alternatives Considered

- html-to-image等でDOMをキャプチャする
    - Canvasのほうが楽そう
- pdf-libで直接PDFを組み立てる
    - 画面用とPDF用で座標計算がズレそうなのでなし
- 画面と同じ解像度のまま書き出す
    - 一番簡単だけど350dpiに届かずざらつくのでなし

## Consequences

- Canvas側の機能だけで完結するので、DOMキャプチャ用のライブラリが要らない
- 高解像度の書き出しはブラウザに負荷がかかるので、パフォーマンス目標（5秒）を実機で確認する
- pixelRatioの計算は関数として切り出してテストする
