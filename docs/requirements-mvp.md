# 要件定義書-MVP

オンラインで画像から手書き文字を抽出し、それをテンプレートに載せて、PDFで任意の大きさで印刷できるアプリ「**SuguYose**」のMVPのための要件定義書です。

機能性を上げる部分はPhase2で行います。

## 1. 背景・目的

現在、オンラインの寄せ書きアプリには大きく分けて2種類あります。

・文字を入力し、あらかじめ決められたフォントでメッセージカードが作られ、企業がそれを発送するタイプのアプリ\
・Canvaのような、多機能アプリの機能の一つとして、手書き文字を抽出・メッセージカードにのっけて、印刷（発送してくれるようなサービスはない）

前者は、フォントが決まっていること、商品の到着を待たなければいけないことがネックになっています。特に手書きでないことは手間をかけていないようにも見えてしまい、渡す側、渡される側どちらにも良い体験ではありません。

後者は、多機能故に操作に習熟するのに時間がかかってしまい、渡す側の負担が大きいです。

ユーザー（幹事）が欲しいものはメンバーが書いた手書きのメッセージカードなので、オンライン上で手書きのメッセージカードの情報をやり取りできれば、すぐにユーザーにメンバーがメッセージカードを手渡しできない状況でも、色紙を作ることが可能になります\
（もちろんユーザーが色紙やカッター、のりなどを用意する必要はあります。これらを解消する機能も実装予定です。）

## 2. 対象ユーザー
幹事を含むメンバー全員

## 3. スコープ
### 3.1 やること
 - 手書きメッセージの画像をアップロードできる
    - JPEGまたはPNG画像をアップロードできる
 - アップロードされた画像を背景透過できる
    - 簡単なノイズ除去ができる
        - メディアンフィルタ
        - スマホ写真特有の粒状ノイズが、透過処理後に黒い点として残らない程度に軽減されていること
    - 簡単な影除去ができる
        - 局所適応2値化
    - 簡単な高画質化ができる
        - シャープ化・コントラスト強調
    - 完全に白黒にできなくてOK
 - テンプレートを選べる
    - 2種類
    - 後から変更可能
 - テンプレートの上に背景を透過した画像を重ねて、サイズを調整できる
    - 拡大・縮小・回転・移動
 - カスタムサイズでA4のPDFに載せて出力できる
    - 印刷の端を避けて配置
    - プリセット + 縦幅でカスタム（mm）
    - 画像も追従する

### 3.2 やらないこと（MVP）
 - 複数プロジェクトの保有
 - 文字色入れ替えなどデコレーション機能
 - 台紙の上に配置する機能

## 4. 非機能要件
 - Webアプリ
    - レスポンシブ対応
    - モバイルファースト
 - テストを適切に作成する
    - Vitest + React Testing Library
    - Playwrightはしない（後から）
 - スタックはReact+TypeScript
 - プライバシー
    - DB接続（Phase2）まではクライアントサイド内で行う
    - サーバーに画像を送信しない
 - パフォーマンス
    - 目標：画像処理10秒
    - 目標：出力5秒
 - 対応ブラウザ
    - Safari / Chrome / Edge最新版
 - 印刷品質
    - 350dpi相当以上の解像度
 - 保守性
    - 画像処理・座標計算などのロジックはUIコンポーネントから分離し、単体テストで担保する。TypeScriptのstrictモードを有効にし、型で防げる誤りは型に任せる。
