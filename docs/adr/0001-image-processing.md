# ADR-0001: 画像処理方式の選定

## Context

SuguYoseは、白紙に書いたペン字の写真からペン字部分以外を透過する機能を持ちます。

スマホ写真など、普通に撮った画像には影やノイズが載ってしまい、白部分のみを透過するだけでは難しいです。そのため、画像処理が必要になります。

## Decision
 - ノイズ除去
    - メディアンフィルタ
 - 影除去
    - 局所適応2値化
 - 高画質化
    - アンシャープマスク
    - コントラスト強調

## Alternatives Considered
- ノイズ除去
    - ガウシアンブラー
        - ペンの線の輪郭もぼやけるのでなし
    - 平均化フィルタ
        - 輪郭もぼやけるしブロックノイズも出やすいのでなし
    - バイラテラルフィルタ
        - エッジは保てるけど重いし実装も大変なのでなし
    - ノンローカルミーンズ
        - 高品質だけど計算コストが重すぎるのでなし
- 影除去
    - グローバル閾値処理（大津の手法など）
        - 画像全体で1つの閾値だと、影をインクと誤判定するのでなし
    - 背景推定による除算（Flat-fielding）
        - 局所適応2値化と近い効果を狙える別のやり方。実装候補
    - ヒストグラム平坦化／CLAHE
        - コントラスト調整の技術で、影の誤検出自体は解決しないのでなし
    - 機械学習による2値化
        - 精度は高いけど学習済みモデルが必要でMVPには重すぎるのでなし
- 高画質化
    - アップスケーリング
        - 学習済みモデルが必要で難易度が高すぎるのでなし。
    - バイキュービック補間など
        - ただ引き伸ばすだけでぼやけるのでなし
    - ガンマ補正
        - 露出補正が目的で、くっきりさせたいのとは違うのでなし

## Processing Order

1. ノイズ除去（メディアンフィルタ）
2. コントラスト強調
3. 局所適応2値化（影除去）
4. テンプレートへの配置（拡大・縮小・回転）
5. アンシャープマスク（シャープ化）

- コントラスト強調は2値化の前にやる
    - 薄いペン跡と紙の差を広げて、2値化の精度を上げるため
- アンシャープマスクは配置の後にやる
    - 拡大縮小・回転で輪郭がまたぼやけるので、最後に仕上げる

## Consequences

- OpenCV.js等を使わず自前実装なので、依存が増えずテストも書きやすい
- 強い影や暗所の写真だと、OpenCV.js等より精度は落ちる
    - 実際の写真で試しながらパラメータ調整が必要
- 完全な白黒にはならないので、テンプレート合成側も半透明前提で作る
